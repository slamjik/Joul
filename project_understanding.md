## 🎯 Суть проекта

**Что делаем:** Web-приложение — комплексная ИС для:
1. Планирования деятельности кафедры (учебная нагрузка)
2. Мониторинга качества обучения (успеваемость студентов)
3. Интерактивной визуализации результатов образовательного процесса (KPI дашборды)

**Бизнес-проблема:** Документация кафедры размещена на разных платформах в разных форматах → нужно централизовать.

**SMART-цель:** Разработать web-приложение → срок **до 25.11.2026**

**Критерий успеха:** Введённое в эксплуатацию web-приложение + оценка «5» за защиту.

## 📦 Модули системы (функциональные блоки)

### 1. Модуль планирования учебной нагрузки
- Распределение часов: дисциплина → преподаватель → группа
- Проверка пересечений по аудиториям и времени
- Экранные формы планов нагрузки (по ТЗ — под требования системного аналитика)

### 2. Модуль мониторинга успеваемости
- Импорт данных из LMS (Moodle/Blackboard) через API
- **Импорт из Excel-таблиц** (учебные планы, ведомости оценок, нагрузка ППС)
- Отображение динамики оценок (графики БРС)
- Выявление студентов в «зоне риска»

### 3. Модуль визуализации KPI (дашборды — встроены в приложение)
> ⚠️ Yandex DataLens **не используется**. Все дашборды строятся внутри приложения (Chart.js / Recharts / Plotly).

- Фильтрация: по периодам / кафедрам / дисциплинам
- Графики: динамика успеваемости, нагрузка, % закрытия часов
- **Наброски с бумаги (фото):**
  - Круговая диаграмма: % уровни кач. образования (60%, 30%...)
  - Диаграмма Венна: пересечения ГиСЭН и других подразделений
  - Таблица по направлениям: дисциплины, группы, нагрузка, часы
  - Карточки по направлению подготовки: 9% ГШ / 58% АГ (% успеваемости по направлениям)
  - Нижняя панель: «Всего ФИО» | «Мониторинг по группам» | «Карта групп»

### 4. Управление доступом (RBAC)
| Роль | Права |
|------|-------|
| Заведующий кафедрой | Полный доступ: просмотр + редактирование |
| Преподаватель | Просмотр своей нагрузки + успеваемость своих групп |
| Администратор | Системное администрирование, управление пользователями |

### 5. Импорт / Экспорт данных
**Импорт в систему:**
- Excel (.xlsx) — учебные планы, ведомости оценок, нагрузка ППС, списки студентов
- LMS API (Moodle/Blackboard) — оценки, активность студентов

**Экспорт из системы:**
- **PDF** — отчёты для аккредитации, сводки по кафедре
- **Excel (.xlsx)** — таблицы нагрузки, ведомости, KPI-сводки
- Назначение: аккредитация + внутренняя отчётность
